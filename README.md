# Claude Code no seu computador · guia gratuito

Guia em PDF de 15 páginas com a instalação do Claude Code pelo aplicativo do Claude e pelo terminal, no Mac e no Windows, os erros mais comuns, os modos de permissão e cinco primeiras tarefas para quem estuda ou trabalha com Direito.

**Página de download:** https://simiao-cavalcante.github.io/guia-claude-code/

**PDF direto:** [guia-claude-code-simiao-cavalcante.pdf](guia-claude-code-simiao-cavalcante.pdf)

## Sobre

Escrito por [Simião Cavalcante](https://instagram.com/simiao_cavalcante), procurador do Município do Rio de Janeiro e professor. Comandos, requisitos e mensagens de erro conferidos em 02/11/2026 na documentação oficial do Claude Code (code.claude.com/docs). Material educativo e independente, sem vínculo com a Anthropic.

A fonte do PDF fica na pasta do post 043 do repositório de postagens (`material/gerar_pdf.py`). Para atualizar, gere o PDF lá, copie para cá com o mesmo nome e publique.

A página é HTML estático, sem dependências de build.
